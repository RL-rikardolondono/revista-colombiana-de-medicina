¿No tiene la contraseña? Cómo crearla (una sola vez)
  1. Inicie sesión en GitHub y abra esta página para crear la contraseña.
  2. En Token name escriba: . En Expiration elija No expiration.
  3. En Repository access elija Only select repositories y marque solo .
  4. En Permissions → Repository permissions, busque Contents y elija Read and write.
  5. Pulse Generate token, copie el código que empieza por github_pat_ y péguelo arriba.

Si pierde el computador, borre esa contraseña en GitHub (Settings → Developer settings → Personal access tokens) y cree una nueva. Las demás webs no se ven afectadas.
